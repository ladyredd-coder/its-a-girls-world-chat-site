# 🎀 It's a Girl's World!

![Status](https://img.shields.io/badge/Status-In_Active_Development-ff69b4) ![License](https://img.shields.io/badge/License-MIT-blue)

Welcome to **It's a Girl's World!** — an interactive, styled dashboard designed as an online sleepover community. This platform is a safe space for real advice, current obsessions, relationship discussions, and bestie-level support.

> 🛠️ **Project Status:** This project is actively being developed and updated! Features, UI enhancements, and backend integrations are being added regularly.

---

## ✨ Features

- **Live Chat Rooms:** Interactive spaces like *Daily Venting*, *Relationship Drama*, and *Late Night Thoughts*.
- **Quick Action Dashboard:** Instant widgets for *Daily Affirmations*, *Mood Check-ins*, and *Anonymous Confessions*.
- **Community Feed:** A visual grid highlighting current fashion trends, lifestyle reports, and daily quote reminders.
- **Y2K Aesthetic Layout:** Custom glassmorphism panels, holographic aura blurs, and a vibrant pink/lavender palette.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 8
- **Styling:** Tailwind CSS 4
- **Linter & Formatter:** Oxfmt

## 🚀 Getting Started

To get a local development copy up and running on your machine:

### 1. Install Dependencies
Make sure you have Node.js installed. Open your terminal in the project directory and run:

npm install

### 2. Start the Development Server
Launch the local server to view the application in your browser:

npm run dev

### 3. Open the App
Once the server starts, open your browser and go to:
http://localhost:5173/
